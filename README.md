Roast Your Own Agent: a program that writes one text to `/output/entry.txt` — a single original line roasting my own AI agent.

> My agent wrote a 500-line plan, held a council meeting, and ran three reviews — all to produce this one line, which it then called a masterpiece.

## Run it

```sh
python3 main.py
```
